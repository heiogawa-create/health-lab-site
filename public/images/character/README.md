# イメージキャラクター画像の差し替え手順

現在このフォルダに入っている3枚のPNGは**仮画像（プレースホルダー）**です。
本番のキャラクター画像（3ポーズ並びのシート）から切り出して、同じファイル名で上書きしてください。

| ファイル名 | 元シートの位置 | ポーズ | 主な使用箇所 |
| --- | --- | --- | --- |
| `hey-fairy-note.png` | 左 | クリップボードにペンで記入 | 監修者プロフィール（AuthorBio）、フッター |
| `hey-fairy-phone.png` | 中央 | スマホ（チェックマーク画面）を掲げる | アフィリエイトCTA（AffiliateCTA） |
| `hey-fairy-check.png` | 右 | チェックリストを提示 | ヘッダーロゴ、記事末尾のあいさつ吹き出し |

## 切り出しのポイント

- 背景は**透過PNG**推奨（白背景のままでも表示は崩れませんが、CTAなど色付き背景の上では透過が望ましいです）
- 1枚あたり **600×600px 前後の正方形** に切り出すとレイアウトが安定します
- キャラクターの周囲に少し余白を残してください

## サイト内での使い方

記事レイアウトやコンポーネントには組み込み済みです。
Astroコンポーネントから任意の場所に置きたい場合は `src/components/CharacterMascot.astro` を使ってください。

```astro
<CharacterMascot pose="check" message="ここにセリフを表示できます" size="md" />
```

- `pose`: `note` / `phone` / `check`
- `message`: 省略するとキャラクターのみ表示
- `size`: `sm` / `md` / `lg`
